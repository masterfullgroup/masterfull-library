# Masterfull Library

Plataforma de biblioteca digital privada para almacenar, organizar, buscar y consultar libros.

## Tecnologías
- React y TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting
- Google Cloud Run
- Google Drive API

## Características
- Sincronización automática con Google Drive
- Catálogo digital de libros
- Usuarios autorizados
- Lector PDF integrado
- Colecciones y búsqueda avanzada
- Panel de administración
